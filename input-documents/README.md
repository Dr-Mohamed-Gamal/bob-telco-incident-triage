# balance-service-deploy

The deployment repository for `balance-service` at Acme Telco, a fictional mobile operator. Merging a change to `deploy/` is what deploys it (GitOps).

| Folder | Contents |
|---|---|
| `deploy/` | Kubernetes manifests |
| `docs/` | Release notes |
| `evidence/` | `kubectl` output and logs saved by the on-call engineer during the incident on 22 Sep 2026 |
| `scripts/` | The demo reset script |

The owner team and tier are in `catalog-info.yaml`. All names, addresses and data are made up.
